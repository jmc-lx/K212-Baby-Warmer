# K212 调奶器项目

## 项目介绍
这是一个基于BF7613（8051内核）的调奶器量产项目，实现了温度控制、LED显示、触摸按键、过零调功等功能。

## 技术栈
- 主控：BF7613BMXX（8051内核，12MHz，SOP20）
- 开发环境：Keil C51
- 编程语言：C语言

## 主要功能
- 8种功能模式：煮沸/除氯/炖煮/调奶/热调/花茶/文火/预约
- 过零调功加热控制：7档功率调节
- NTC温度采集：中值平均滤波，温度精度±2℃
- LED矩阵动态扫描显示：8根IO线驱动56个LED
- 电容触摸按键：消抖+长短按处理
- 多重安全保护：提壶检测、干烧保护、传感器故障检测、风扇故障检测
